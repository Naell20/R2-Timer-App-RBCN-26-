# R2-Timer-App-Robocon26-

Timer Count  utnuk Robot 2

1. Meihua Forest, dilegkapi dengan fitur
   1. Klik pertama, data waktu akan langsung tercatat jika R2 sudah mengambil kotak di MF
   2. Klik kedua, menandakan bahwa kotak yang tadinya diambil terjatuh atau gagal diambil (warna blok langsung merah
   3. Klik ketika, menandakan R2 berhasil mengambil kembali kotak yang jatuh/terjatuh

2. Timer dilengkapi dengan Mode (Try Mode) yang digunakan untuk latihan berulang tanpa batasan waktu, serta dilengkapi dengan rata-rata assembly pada tiap match
